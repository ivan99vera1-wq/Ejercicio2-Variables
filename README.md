## 📖 Descripción

Este es el **Ejercicio 2** de mi serie de práctica en Java. El programa declara
variables de distintos tipos (`String`, `int`, `double`), les asigna valores y
los muestra por consola concatenándolos con texto.

> 🎯 **Objetivo del ejercicio:** aprender a declarar variables, elegir el tipo
> de dato adecuado y concatenar valores con `+` dentro de `System.out.println()`.

## ✨ Qué hace

Declara estos datos:

```java
String nombre   = "Ivan";
String ciudad   = "Madrid";
int    edad     = 27;
double altura   = 1.79;
```

Y imprime:

```
Me llamo Ivan
Tengo 27 años
Vivo en Madrid
Mido 1.79 metros
```

## 🧠 Conceptos practicados

| Concepto | Descripción |
|:--|:--|
| `String` | Cadena de texto |
| `int` | Números enteros |
| `double` | Números con decimales |
| Concatenación `+` | Unir texto y variables en un solo `println` |

## 🛠️ Requisitos

- **JDK 8** o superior ([Descargar JDK](https://adoptium.net/))
- Un editor: IntelliJ IDEA, VS Code o similar
- Terminal o símbolo del sistema

## ▶️ Cómo ejecutarlo

```bash
# 1. Compilar
javac src/Main.java

# 2. Ejecutar
java -cp src Main
```

O directamente desde **IntelliJ IDEA** → botón ▶ *Run*.
